# Derpi Triple Shot — derpibooru 一键三连

一个用户脚本：在 derpibooru 页面上加一个**浮动按钮**，点击即完成**收藏 + 点赞 + 下载**（下载到 `下载\derpi\`，文件名用站内原版命名）。搜索网格页支持**目标记忆**（悬停哪张圈哪张），详情页三连成功后**自动回搜索页**。

## 安装（Chrome + Tampermonkey，两个开关缺一不可）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（脚本管理器，用户脚本的运行容器）。
2. 打开 `chrome://extensions` → 右上角打开**开发者模式**。
3. 关键一步：在 Tampermonkey 卡片上点「详情」→ 打开**允许用户脚本**（Allow User Scripts）。
   > Chrome 138+ 必须开，否则脚本能装上但跨域请求/下载**静默失效**——这是"装了没反应"的头号原因。
4. Tampermonkey 图标 → 添加新脚本 → 全选删掉模板 → 粘贴 `derpi-triple-shot.user.js` 全文 → Ctrl+S 保存。
5. Tampermonkey 设置 → 下载模式 → 选 **Browser（浏览器）**，`derpi\` 子目录才会生效。

## 用法

- **快捷键 F（0.2.0 起主推）**：网格页鼠标停在某张图上按 F＝站内原生收藏+点赞（星星实时点亮）+ 插件补下载；详情页按 F＝同上 + 约半秒自动返回。搜索框打字、Ctrl/Alt/Shift 组合、按键连发一律不触发；换键改配置区 `hotkey` 一个字母即可。三连亦可走按钮左键（0.2.16 起详情/网格统一）。
- **快捷键 D（0.2.1）**：网格页悬停某图按 D = 当前标签页进入该图详情页（保留搜索上下文）；详情页按 D = 直接返回上一页。与 F 组成纯键盘流转环：悬停 → F 收进仓库 / D 细看 → D 回网格。
- **快捷键 E（0.2.5）**：搜索/标签网格页按 E = 翻到下一页（走站内自己的 Next 链接，浏览上下文全保留）；已在最后一页会提示。
- **快捷键 C / X（1.3.2 起并列，曾用 W）**：站内按启用的键 = **记忆当前网址并切到中性页面**（默认必应；菜单「🌐 设置中性页面」可改，弹窗输入即存）；在**任何非 derpibooru 页面**按启用的键 = 跳回记忆的网址（未记忆过则浮条提示）。**启用哪个键由你选**：菜单「🎛 启用离开键」输入 `c`、`x` 或 `cx`（都启用），留空恢复默认 C+X。为此脚本匹配范围为全部网站（站外仅离开键生效，无按钮无其他功能）。备选离开动作 `close`（尝试关标签）保留在配置区。
- **快捷键 W（1.1.0）**：尝试关闭当前标签页（best-effort）。Chrome 只放行“脚本弹出的标签”，正常浏览的标签会被静默拒绝——被拒时浮条提示改用 Ctrl+W / Alt+F4。
- **去屏蔽键（原 W）— 已暂时移除（0.2.15）**：曾在详情页按 W 解除过滤器屏蔽；因仍不工作，按用户要求暂摘除待后续开发（git 历史 0.2.9–0.2.14 保留完整实现与开关）。W 键后曾用作关标签与离开，1.3.1 起该职责移交 C 键，W 现无绑定。
- **按钮**：**左键** = 三连（收藏+点赞+下载，详情/网格统一；详情页完成约半秒自动返回）；**详情页右键** = 返回上一页（0.2.16）。
- **搜索网格页**：鼠标悬停某张缩略图（出现绿色圈＝已锁定目标）→ **左键** = 三连该图。
- 按钮半透明、可拖动、位置自动记忆；**绿＝全成功，红＝有失败**（页面底部浮条说明原因）。
- Tampermonkey 菜单：**⏱ 设置自动返回延时**（输入毫秒数即存即生效；0=秒回，留空恢复默认随机区间；存于脚本存储，换装不丢）、**🌐 设置中性页面（离开目标）**（弹窗输入即存，留空恢复默认）、**🎛 启用离开键（C/X/都开）**、**🎯 重置按钮位置**。（发布版已移除自检与活动日志等调试项。）

## fixtures（给开发者会话的真实页面样本）

开发环境的终端到不了 derpibooru，选择器要靠真实页面结构验证。请存两个页面放进 `fixtures\`：

1. 任意一张图的**详情页**；
2. 一个**搜索结果页**（网格页）。

方法：页面上 `Ctrl+S` → 保存类型选**「网页，仅 HTML」**→ 存进本项目的 `fixtures\` 文件夹（文件名随意）。

> 隐私说明：登录态保存的页面 HTML 可能含你的用户名，`.gitignore` 已忽略 `fixtures/*.html`，不会被 git 提交。

存好后运行 `node tests/fixture-check.mjs`（或直接把 fixture 交给开发会话），即可核对选择器假设。

## 配置

全部在 `derpi-triple-shot.user.js` 顶部「配置区」，改一行字即可：

| 项 | 默认 | 说明 |
|---|---|---|
| `downloadSubfolder` | `'derpi'` | 下载子目录；`''` 存下载根目录 |
| `autoBack` | `true` | 详情页成功后自动回上一页 |
| `autoBackDelayMs` | `[300, 600]` | 默认返回延时区间（毫秒）；**菜单「⏱ 设置自动返回延时」设过的固定值优先**，菜单里留空即恢复此区间 |
| `triShotTiming` | `'dispatch'` | 按钮三连的时序：`dispatch` 发出即走（默认）/ `stagger` 错峰等回包 / `parallel` / `serial`（F 键恒为发出即走，不受此项影响） |
| `hotkey` | `'f'` | 0.2.0 键盘三连：收藏点赞走站内原生 F，插件补下载（详情页附自动返回）；撞了改这一个字母 |
| `navHotkey` | `'d'` | 0.2.1 导航键：网格 D=进悬停图详情页（当前标签页）；详情页 D=返回上一页 |
| `pageHotkey` | `'e'` | 0.2.5 翻页键：搜索/标签页 E=翻到下一页（站内 Next 链接） |
| `leaveHotkeys` | `['c','x']` | 1.3.2 离开键（C/X 并列）：菜单「🎛」输入 c / x / cx 选择启用，留空恢复默认 |
| `leaveAction` | `'neutral'` | 离开动作：`neutral` 切中性页面（定稿）/ `close` 尝试关标签（备选） |
| `neutralUrl` | `'https://www.bing.com'` | 中性页面默认值（菜单「🌐」设置优先；须 http(s) 站点，空白页不加载脚本） |
| `staggerMs` | `300` | 错峰模式下下载晚发车的毫秒数（收藏先走，避免大图抢带宽） |
| `buttonDefault` | `{xPct:96, yPct:40}` | 首次停靠位置；拖动后记忆（菜单可重置） |
| `debug` | `true` | 控制台 `[DTS]` 日志 |

## 排障

| 症状 | 原因与处理 |
|---|---|
| 脚本装上了但按钮不出现 | 「允许用户脚本」或「开发者模式」没开（见安装第 2/3 步） |
| 提示「未登录」 | 先在站点登录；脚本不碰你的密码，只借你已登录的页面发请求 |
| 下载没有子目录 | Tampermonkey 下载模式没选 Browser（见安装第 5 步）；脚本会自动退化成 `derpi_` 前缀平铺 |
| 提示「找不到防伪暗号」 | 页面结构刷新重试；仍失败把报错原文交给开发会话（发布版无自检，开发用 git 历史 0.2.x 的调试工具） |
| 想改文件名规则 | 站内原版名来自站方下载头的 Content-Disposition，脚本原样采用；退化模板在配置区改 |
