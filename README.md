# Derpi Triple Shot — derpibooru 一键三连

一个用户脚本：在 derpibooru 页面上加一个**浮动按钮**，点击即完成**收藏 + 点赞 + 下载**（下载到 `下载\derpi\`，文件名用站内原版命名）。搜索网格页支持**目标记忆**（悬停哪张圈哪张），详情页三连成功后**自动回搜索页**。

## 安装（Chrome + Tampermonkey，两个开关缺一不可）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)（脚本管理器，用户脚本的运行容器）。
2. 打开 `chrome://extensions` → 右上角打开**开发者模式**。
3. 关键一步：在 Tampermonkey 卡片上点「详情」→ 打开**允许用户脚本**（Allow User Scripts）。
   > Chrome 138+ 必须开，否则脚本能装上但跨域请求/下载**静默失效**——这是"装了没反应"的头号原因。
4. Tampermonkey 图标 → 添加新脚本 → 全选删掉模板 → 粘贴 `derpi-triple-shot.user.js` 全文 → Ctrl+S 保存。
5. Tampermonkey 设置 → 下载模式 → 选 **Browser（浏览器）**，`derpi\` 子目录才会生效。

## 用法

- **详情页**（点开大图）：点浮动按钮 → 收藏+点赞+下载 → 变绿 → 1–3 秒后自动回搜索页。
- **搜索网格页**：鼠标悬停某张缩略图（出现绿色圈＝已锁定目标）→ 点浮动按钮 → 三连该图。
- 按钮半透明、可拖动、位置自动记忆；**绿＝全成功，红＝有失败**（页面底部浮条说明原因）。
- Tampermonkey 菜单里有「▶️ 自检当前页面」（排障用）和「🎯 重置按钮位置」。

## fixtures（给开发者会话的真实页面样本）

开发环境的终端到不了 derpibooru，选择器要靠真实页面结构验证。请存两个页面放进 `fixtures\`：

1. 任意一张图的**详情页**；
2. 一个**搜索结果页**（网格页）。

方法：页面上 `Ctrl+S` → 保存类型选**「网页，仅 HTML」**→ 存进本项目的 `fixtures\` 文件夹（文件名随意）。

> 隐私说明：登录态保存的页面 HTML 可能含你的用户名，`.gitignore` 已忽略 `fixtures/*.html`，不会被 git 提交。

存好后运行 `node tests/fixture-check.mjs`（或直接把 fixture 交给开发会话），即可核对选择器假设。

## 配置

全部在 `derpi-triple-shot.user.js` 顶部「配置区」，改一行字即可：

| 项 | 默认 | 说明 |
|---|---|---|
| `downloadSubfolder` | `'derpi'` | 下载子目录；`''` 存下载根目录 |
| `autoBack` | `true` | 详情页成功后自动回上一页 |
| `autoBackDelayMs` | `[300, 600]` | 返回前停顿毫秒区间；真·发出即走写 `[0,0]`（绿提示就完全看不到了） |
| `triShotTiming` | `'dispatch'` | 三连时序：`dispatch` 发出即走（收藏+下载请求发车就返回，不等回包；发出前预检登录）/ `stagger` 错峰等回包 / `parallel` / `serial` |
| `staggerMs` | `300` | 错峰模式下下载晚发车的毫秒数（收藏先走，避免大图抢带宽） |
| `buttonDefault` | `{xPct:96, yPct:40}` | 首次停靠位置；拖动后记忆（菜单可重置） |
| `debug` | `true` | 控制台 `[DTS]` 日志 |

## 排障

| 症状 | 原因与处理 |
|---|---|
| 脚本装上了但按钮不出现 | 「允许用户脚本」或「开发者模式」没开（见安装第 2/3 步） |
| 提示「未登录」 | 先在站点登录；脚本不碰你的密码，只借你已登录的页面发请求 |
| 下载没有子目录 | Tampermonkey 下载模式没选 Browser（见安装第 5 步）；脚本会自动退化成 `derpi_` 前缀平铺 |
| 提示「找不到防伪暗号」 | 页面结构变了或 fixture 未验证——跑自检，把输出发给开发会话 |
| 想改文件名规则 | 站内原版名来自站方下载头的 Content-Disposition，脚本原样采用；退化模板在配置区改 |

## 开发里程碑

- **M1（当前）**：骨架 + 配置区 + 自检 + 离线 fixture 检查工具。
- **M2**：详情页三连核心实测打通（依据 fixtures 收口选择器）。
- **M3**：网格目标记忆 + 浮动按钮打磨。
- **M4**：自动回搜索页 + 状态反馈收尾。
