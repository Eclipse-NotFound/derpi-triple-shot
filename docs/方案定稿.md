# 方案定稿（2026-09-07，grilling 四问 + 两问拍板）

> 本文件是 `derpi-triple-shot` 立项时的共享理解记录。开发会话开工先读此文件。

## 一句话

derpibooru 用户脚本：浮动按钮一键**收藏+点赞+下载**；网格页目标记忆，详情页成功后自动回搜索页；下载到 `下载\derpi\`，用站内原版文件名。

## 已拍板的决策

| 决策点 | 结论 |
|---|---|
| 形态 | 用户脚本（Tampermonkey），不上架；核心逻辑保留包扩展壳的可能 |
| 浏览器 | Chrome（Chromium 系）；必须文档化「开发者模式 + 允许用户脚本」双开关 |
| 页面范围 | v1 = 详情页 + 搜索网格缩略图；批量功能不做 |
| 项目位置 | `D:\活\工具\derpi-triple-shot\`，独立 git 仓库 |
| 文件名/位置 | 站内原版下载文件名（Content-Disposition），存 `下载\derpi\` 子目录 |
| 按钮 | 统一浮动按钮（半透明/可拖/位置记忆）；网格页目标记忆+高亮圈防误点（F1=A） |
| 反馈 | 全成功=绿，任一失败=红+浮条明细；三动作独立记账 |
| 自动回页（F2） | 成功后随机 1–3 秒：同标签 `history.back()`；新标签尽力 `window.close()`（拦不住不算失败）；无站内来路不跳 |

## 无需拍板的默认值

兄弟站兼容门留配置（v1 只激活 derpibooru）；重复点击无害（幂等）；下载重名浏览器自动加 (1)；未登录不重试风暴；GM_download 子目录失败自动退化为 `derpi_` 前缀平铺。

## 技术事实（源码核验，2026-09-07，腿 A 实测✓）

来源：[philomena router.ex](https://github.com/philomena-dev/philomena/blob/master/lib/philomena_web/router.ex)、[openapi.yaml](https://github.com/philomena-dev/philomena/blob/master/openapi.yaml)、fave/vote 控制器源码（引句见会话档案）。

1. **写操作不在 JSON API 里**：`/api/v1/json/` 只有读与搜索。收藏 = `POST /images/{id}/fave`，点赞 = `POST /images/{id}/vote`（body `up=true/false`）；挂在 `:browser` 管道下，需**登录会话 cookie + CSRF**（Phoenix 默认读 `x-csrf-token` 头），`key=` 参数不被接受。→ 工具必须注入已登录站内页面，同源发请求。
2. **收藏自带点赞**：`FaveController.create` = 删旧收藏→建新收藏→删旧投票→建 up 投票，一个事务；重复点幂等。→ 三连 = fave + download 两个请求。
3. **原图直链** = 图片 JSON `representations.full`（CDN `/img/view/年/月/日/{id}.{ext}` 形态）；站内下载文件名走下载响应头 Content-Disposition（`/img/download/` 变体待线上验证🧪）。
4. **无 CORS 放行头**：站外直连被浏览器拦 → 必须站内同源（写）+ GM_xmlhttpRequest（读 CDN 头）。
5. **限流**：普通 30 次/5 秒、搜索 20 次/10 秒；风控 501（HTML）要退避、500 空体停 ≥15 分钟。单次点按 2–3 请求，远低于限。
6. **API key 不需要**（仅读私人过滤视图才要，未纳入 v1）。
7. **平台**：Chrome MV2 已死（2026-08-31 商店清空），MV3 唯一；Tampermonkey 需「开发者模式 + 允许用户脚本」双开关，否则 GM 功能静默失效（[Tampermonkey FAQ Q209](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)）。
8. **轮子空档**：AMO/GreasyFork/GitHub 无「单图收藏+点赞+下载」组合工具；官方明文欢迎第三方工具（旁证△）。

## 待验证（开发第一步，fixtures/自检解决）
